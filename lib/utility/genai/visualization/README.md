# Visualization

Plotly-based helpers for inspecting NLP and GenAI learning results. Available
visualizations include embedding projections, similarity and attention
heatmaps, n-gram frequency bars, chunk-size and semantic-breakpoint plots,
positional encodings, and metric/line plots. `mermaid_html` helps embed graph
diagrams in HTML reports.

Import functions from `lib.utility.genai.visualization`; each function returns
a Plotly figure or HTML fragment suitable for the report helpers. See the
numbered scripts in `Module-5/GENAI/` for usage.
