# Deep Learning Framework

A modular deep learning framework supporting TensorFlow and PyTorch.

## Goals

- Framework agnostic architecture
- TensorFlow support
- PyTorch support
- Reusable training pipeline
- Reusable evaluation pipeline
- Consistent model wrappers
- Shared optimization strategies
- Shared visualization utilities

## Folder Structure

abstractions/
Framework interfaces

config/
Configuration management

evaluation/
Model evaluation

frameworks/
Framework implementations

optimization/
Optimizers, losses, callbacks, schedulers

visualization/
Plotting and reporting utilities
